# Recommended Official Claude Code Plugins

Use Anthropic's official marketplace and review permissions before installation.

Start with:
- `github@claude-plugins-official`
- Official language/LSP plugins matching the actual Xspeeria stack
- `document-skills@anthropic-agent-skills`
- `example-skills@anthropic-agent-skills` (reference/examples; install only if useful)

Commands:
```text
/plugin
/plugin install github@claude-plugins-official
/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills
/plugin install example-skills@anthropic-agent-skills
```
Do not install random plugins merely because they are popular.
