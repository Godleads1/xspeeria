# ADR-050 — Support Runs Through Admin Disputes; Referral On Hold

| Attribute | Value |
|---|---|
| **Status** | **APPROVED** — 2026-10-19 |
| **Decision ID** | DEC-057 |
| **Authority** | Product owner, 2026-10-19: "Support: … Your admin Disputes screens could serve as the support system. Should they?" → "yes"; "Referral: needs the reward rules" → "Yes. but hold on". |

## Decision

1. **Support**: the admin console's Disputes module is also the support ticket system (the app's Support screen opens a case there). Designed with the admin build; no separate helpdesk vendor.
2. **Referral**: approved in principle, **on hold**. Nothing is built until the owner gives the reward rules (who earns what, when, limits) and compliance has looked at them.
